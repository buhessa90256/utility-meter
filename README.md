# عدّاد | Utility Meter

موقع عربي لإدارة قراءات الكهرباء والماي لثلاثة بيوت. يعمل بدون خادم أو تسجيل دخول، وتُحفظ البيانات في المتصفح على الجهاز فقط.

## الميزات

- أسعار قابلة للتعديل (الكهرباء 0.067، الماي 2.090).
- قراءات شهرية وسجل لكل بيت، مع القراءة السابقة التلقائية.
- توزيع فرق إجمالي الفاتورة بالتساوي، مع ضبط التقريب بالفلس.
- عداد خربان: متوسط آخر 3 أو 5 أو 6 أشهر فعلية متوفرة.
- تغيير عداد: نهاية القديم وبداية الجديد وقراءة الجديد الحالية.
- لوحة ملخّص ورسوم آخر 6 شهور، تعديل وحذف واسترجاع آخر 12 حساباً محذوفاً.
- نسخ احتياطي JSON مع التحقق، استرجاع، تصدير CSV، نسخ ملخّص وطباعة.
- PWA للعمل بدون اتصال بعد أول زيارة. من قائمة المتصفح اختر إضافة للشاشة الرئيسية.

## التشغيل والاختبار

يتطلب Node.js 20 أو أحدث. لا توجد حزم خارجية.

```sh
npm test
npm run dev
```

افتح http://127.0.0.1:4173. للنشر على GitHub Pages اختر Settings → Pages → Deploy from a branch → main / (root).

## الحسابات والبيانات

الاستهلاك = الحالية − السابقة. عند تغيير العداد: (نهاية القديم − السابقة) + (الحالية − بداية الجديد). الأشهر التقديرية لا تدخل في المتوسط. تُزاد الكميات التقديرية على آخر قراءة فعلية عند تعبئة القراءة السابقة كي لا تُحسب مرتين. عدد أشهر المتوسط الفعلي يظهر قبل الحفظ.

يُقرّب سعر الكهرباء والماي لكل بيت إلى أقرب فلس أولاً؛ يوزع فرق الفاتورة بالفلس بالتساوي ويخصص باقي الفلوس للبيوت بالترتيب، بحيث يطابق مجموع المبالغ الفاتورة تماماً. الفاتورة التي تؤدي إلى مبلغ نهائي سالب لأي بيت تُرفض.

كل حساب شهري يحتفظ بالأسماء والأسعار والقراءات التي استُخدمت فيه. تعديل شهر قديم لا يعيد حساب الشهور اللاحقة؛ راجعها يدوياً. لا يوجد اتصال بشركة الكهرباء أو فواتير حكومية، والأسعار قابلة للتخصيص ولا تُقدّم كتعرفة رسمية.

القراءات المقروءة لا تُنشر في GitHub. يدعم الموقع استيراد سجل خاص مشفّر بـ AES-256-GCM: يوجد الملف المشفّر فقط في المستودع، ومفتاح الفتح في جزء الرابط بعد # ولا يُرسل إلى الخادم. من لديه رابط الفتح الكامل يستطيع قراءة السجل، لذلك احتفظ به لنفسك. تُفك البيانات وتُحفظ محلياً على جهاز من يفتح الرابط. لا يتزامن أي تعديل لاحق تلقائياً بين الأجهزة. يحافظ الاستيراد على الشهور الموجودة ويترك الشهور المتعارضة للمراجعة؛ ولا يعيد الاستيراد عند فتح نفس الرابط مرة أخرى.

السجلات التي لم يُحدد شهرها تبقى في الأرشيف الأصلي ولا تدخل في إجماليات الشهور. التقديرات التاريخية تحفظ سبب التقدير ومرجع العداد الجديد إن وُجد، لتبدأ القراءة القادمة من المرجع الصحيح. الحسبات تُعاد من القراءات والأسعار، ولا تُنسخ الأخطاء الحسابية في المحادثات القديمة.

قد تضيع البيانات عند مسح بيانات المتصفح؛ احتفظ بنسخة JSON دورية. قبل الاسترجاع تُحتفظ نسخة تلقائية محلية بمفتاح `utility-meter-v1-before-restore`، وقبل استيراد السجل الخاص بالمفتاح `utility-meter-v1-before-history-import`. الملفات المحذوفة مؤقتة ولا تدخل في النسخة المُسترجعة. خط Google اختياري، ويعمل الموقع بخط النظام دون الإنترنت.
